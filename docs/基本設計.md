# 基本設計

## 1. 全体構成
- **アプリケーションタイプ**: Webアプリケーション
- **対応デバイス**: デスクトップ、スマートフォン（PWA対応）
- **使用技術**:
  - フロントエンド: React + TypeScript
  - 物理演算: matter.js
  - ビジュアル: Canvas API または WebGL
  - PWA: manifest.json + Service Worker

---

## 2. 機能設計

### 2.1 物質の落下シミュレーション
- **画面構成**:
  - 落下物の表示領域
  - 床の表示
  - 落下距離の目盛り
- **操作**:
  - 「開始」ボタンでシミュレーション開始
  - シミュレーション中は物理演算に基づき、落下物の位置と速度を更新
- **物理演算**:
  - 重力加速度: `9.8 m/s^2`
  - 空気抵抗: シンプルなモデルを採用
  - 衝突判定: matter.jsの衝突検出機能を利用

---

### 2.2 パラメータ設定
- **UI要素**:
  - 質量、形状、材質の選択（ドロップダウンまたはスライダー）
  - 床の材質と硬さの選択
  - 落下距離の設定（数値入力またはスライダー）
- **バリデーション**:
  - 入力値が範囲外の場合、エラーメッセージを表示

---

### 2.3 PWA対応
- **manifest.json**:
  - アプリ名、アイコン、テーマカラーを設定
- **Service Worker**:
  - 静的リソースのキャッシュ
  - オフライン時のエラーページ表示

---

### 2.4 落下衝撃ランキング
- **データ保存**:
  - ローカルストレージにランキングデータを保存
  - 必要に応じてサーバー連携を検討
- **ランキング表示**:
  - ユーザー名、スコア、日付をテーブル形式で表示

---

### 2.5 ビジュアル・アニメーション
- **アニメーション**:
  - Canvas APIまたはWebGLで落下物の動きを描画
  - 衝突時のエフェクト（破片、揺れなど）を追加
- **デザイン**:
  - シンプルで直感的なUI
  - 色やフォントは視認性を重視

---

## 3. ディレクトリ構成
```
/src
  ├ components/    // UIコンポーネント
  ├ physics/       // 物理演算ロジック
  ├ assets/        // 画像・アイコン等
  ├ App.tsx        // アプリケーションのエントリーポイント
  └ index.tsx      // Reactのエントリーポイント
/public
  ├ manifest.json  // PWA設定
  └ index.html     // HTMLテンプレート
/service-worker.js // Service Workerスクリプト
```

---

## 4. 使用ライブラリ
- **React**: UI構築
- **TypeScript**: 型安全性の向上
- **matter.js**: 物理演算エンジン
- **Canvas API / WebGL**: ビジュアル描画
- **Workbox**: Service Workerの管理
