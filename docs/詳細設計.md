# 詳細設計

## 1. 全体構成
- **アプリケーションタイプ**: Webアプリケーション
- **対応デバイス**: デスクトップ、スマートフォン（PWA対応）
- **使用技術**:
  - フロントエンド: React + TypeScript
  - 物理演算: matter.js
  - ビジュアル: Canvas API または WebGL
  - PWA: manifest.json + Service Worker

---

## 2. 機能詳細

### 2.1 物質の落下シミュレーション
#### 画面構成
- **落下物の表示領域**:
  - Canvasを使用して描画。
  - 落下物の形状（円形、四角形など）を選択可能。
- **床の表示**:
  - 固定位置に描画。
  - 床の材質に応じた色やテクスチャを設定。
- **落下距離の目盛り**:
  - Canvas上に目盛りを描画。
  - 目盛りの単位（メートル）を表示。

#### 操作
- **「開始」ボタン**:
  - ボタン押下時に物理演算を開始。
  - ボタンはReactコンポーネントとして実装。

#### 物理演算
- **重力加速度**:
  - 定数として`9.8 m/s^2`を設定。
- **空気抵抗**:
  - シンプルなモデル（例: `F = -kv`）を採用。
- **衝突判定**:
  - matter.jsの衝突検出機能を利用。
  - 衝突時の反発係数を設定可能。

---

### 2.2 パラメータ設定
#### UI要素
- **質量、形状、材質の選択**:
  - ドロップダウンメニューまたはスライダーで選択。
  - 質量は数値入力も可能。
- **床の材質と硬さの選択**:
  - ドロップダウンメニューで選択。
  - 硬さはスライダーで調整。
- **落下距離の設定**:
  - スライダーまたは数値入力で設定。

#### バリデーション
- **入力値の範囲**:
  - 質量: 0.1kg～100kg
  - 落下距離: 1m～100m
- **エラーメッセージ**:
  - 範囲外の値が入力された場合、警告を表示。

---

### 2.3 PWA対応
#### manifest.json
- **アプリ名**: Physics Simulator
- **アイコン**: 192x192, 512x512のPNGファイルを用意。
- **テーマカラー**: #ffffff（白）

#### Service Worker
- **キャッシュ対象**:
  - HTML、CSS、JavaScript、画像ファイル。
- **オフライン時の挙動**:
  - オフライン用のエラーページを表示。

---

### 2.4 落下衝撃ランキング
#### データ保存
- **ローカルストレージ**:
  - ユーザー名、スコア、日付をJSON形式で保存。
- **サーバー連携**:
  - 必要に応じてAPIを設計。

#### ランキング表示
- **テーブル形式**:
  - 列: ユーザー名、スコア、日付。
  - ソート機能を実装。

---

### 2.5 ビジュアル・アニメーション
#### アニメーション
- **落下物の動き**:
  - Canvas APIまたはWebGLで描画。
  - フレームごとに位置を更新。
- **衝突時のエフェクト**:
  - 床の揺れ、破片の飛散をアニメーションで表現。

#### デザイン
- **UIテーマ**:
  - シンプルで直感的なデザイン。
  - 色やフォントは視認性を重視。

---

## 3. ディレクトリ構成
```
/src
  ├ components/    // UIコンポーネント
  ├ physics/       // 物理演算ロジック
  ├ assets/        // 画像・アイコン等
  ├ App.tsx        // アプリケーションのエントリーポイント
  └ index.tsx      // Reactのエントリーポイント
/public
  ├ manifest.json  // PWA設定
  └ index.html     // HTMLテンプレート
/service-worker.js // Service Workerスクリプト
```
