# 実装方針

## 1. 全体構成
Webアプリケーションとして開発し、PWA（Progressive Web App）対応とすることでスマホにもインストール可能にする。  
フロントエンドはReactやVueなどのモダンなフレームワークを利用し、ビジュアルやアニメーションの実装を容易にする。  
物理演算部分はJavaScript/TypeScriptで実装し、必要に応じて物理エンジン（例：matter.js）を利用する。

## 2. 主要機能ごとの実装方針

### 2.1 物質の落下シミュレーション
- 画面上に「落下物」「床」「落下距離」を視覚的に表示。
- 「開始」ボタンで落下アニメーションを開始し、物理演算に基づいて落下・衝突をシミュレート。
- 落下物の運動方程式（重力加速度、空気抵抗など）を計算し、位置・速度をフレームごとに更新。

### 2.2 パラメータ設定
- UI上で以下のパラメータを設定できるようにする：
    - 落下物：質量、形状、材質
    - 床：材質、硬さ
    - 落下距離：数値入力またはスライダーで設定
- 入力値のバリデーションを行い、異常値は警告表示。

### 2.3 PWA対応
- `manifest.json`とService Workerを用意し、PWAとしてインストール可能にする。
- オフライン時の挙動も考慮し、必要なリソースはキャッシュする。

### 2.4 落下衝撃ランキング
- シミュレーション結果（衝撃の大きさなど）をスコア化し、ランキングとして表示。
- ローカルストレージやサーバー（必要に応じて）にランキングデータを保存。
- ユーザー名入力や日付表示も検討。

### 2.5 ビジュアル・アニメーション
- CanvasやSVG、もしくはWebGLを利用して、落下・衝突時のアニメーションを実装。
- 衝撃時にはエフェクト（例：床の揺れ、破片の飛散など）を追加し、視覚的に分かりやすくする。
- デザインはシンプルかつ見やすいものを心がける。
